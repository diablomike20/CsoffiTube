# <img src="desktop/icon.png" align="top" height="44"> CsoffiTube

Android, iOS és asztali alkalmazás a YouTube és YouTube Music számára.

Letöltés: közvetlenül a GitHub Release oldalról.

[<img src="https://img.shields.io/badge/GitHub%20Releases-100000?style=for-the-badge&logo=github"
      alt="GitHub Releases"
      hspace="16"
      height="50">](https://github.com/diablomike20/CsoffiTube/releases/latest)

A Linux, macOS és Windows változatok a [CsoffiTube Desktop](https://github.com/diablomike20/CsoffiTube-Desktop) repositoryban érhetők el.

## Funkciók

- Nincs reklám
- Háttérben is lejátszik
- Kezelheted a videó/zene könyvtárat bejelentkezés nélkül
- Kezelheted a megtekintési előzményeket bejelentkezés nélkül
- Videó letöltése
- RSS hírfolyam olvasó YouTube csatornákhoz
- Rövid videók elrejtése
- Élő chat
- Eredeti hang lejátszása
- Testreszabás CSS-sel

## Hogyan működik

- A https://m.youtube.com és https://music.youtube.com webes tartalmat Android WebViewbe csomagolja
- Kód injektálása a hirdetések blokkolására
- Lejátszási vezérlők bekötése és háttérlejátszás támogatása
