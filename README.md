## Funkciók

- Nincs reklám
- Háttérben is lejátszik
- Kezelheted a videó/zene könyvtárat bejelentkezés nélkül
- Kezelheted a megtekintési előzményeket bejelentkezés nélkül
- Videó letöltése
- RSS hírfolyam olvasó YouTube csatornákhoz
- Rövid videók elrejtése
- Élő chat
- Eredeti hang lejátszása
- Testreszabás CSS-sel

## Hogyan működik

- A https://m.youtube.com és https://music.youtube.com webes tartalmat Android WebViewbe csomagolja
- Kód injektálása a hirdetések blokkolására
- Lejátszási vezérlők bekötése és háttérlejátszás támogatása
